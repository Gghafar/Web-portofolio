    LLM inference endpoint · May – Jun 2026 · AI/ML Engineer

    DFK Text Classifier

    A fine-tuned 8-billion-parameter language model served as a GPU-backed API. It reads Indonesian social-media posts and sorts them into a five-label schema for disinformation, slander, and hate speech (DFK).

    Model
    Ministral-8B-DFK, fine-tuned, 8B parameters
    Serving
    FastAPI endpoint on Modal
    Hardware
    NVIDIA H100
    Precision
    Full bfloat16 with Unsloth FastLanguageModel
    Cold starts
    Weights cached on a persistent Modal Volume across container restarts
    Decoding
    MTLA voting: N trials, confidence scored from logits over the first K = 10 tokens, majority vote
    Guardrails
    Label normalization to the public schema; a relevance filter drops unrelated context before prompting
    Tracing
    W&B Weave traces plus JSONL backups: inputs, outputs, latency, and token counts per request
    • Python
    • FastAPI
    • Modal
    • Unsloth
    • W&B Weave
